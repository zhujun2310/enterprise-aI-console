# Modules

## 当前模块

- `Dashboard`：AI Native 首页，见 `docs/sprints/sprint-2-dashboard.md`
- `RBAC / Auth`：认证、角色、权限、菜单、路由与 API 鉴权，见 `docs/sprints/sprint-1-rbac.md`
- `Bootstrap / Workspace`：工程底座、Monorepo、CI 与文档目录初始化，见 `docs/sprints/sprint-0-bootstrap.md`
- `Device Center`：设备中心主链路，当前已完成实现，后续可补独立模块文档

## 阅读顺序建议

- 先看 `Sprint 0`，了解工程结构
- 再看 `Sprint 1`，理解认证和权限边界
- 最后看 `Sprint 2`，理解首页模块、实时能力与 Widget 机制
