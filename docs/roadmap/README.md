# Roadmap

Milestones and delivery plans.

## Current Status

- Sprint 0: 基础工程与 Monorepo 搭建，已完成
- Sprint 1: RBAC 权限体系闭环，已完成
- Sprint 2: Dashboard 首页与可视化基础能力，已完成
- Sprint 3: 设备中心主链路，已完成
- Sprint 4: 数字化大屏，待开始

## Sprint 3 Deliverables

- 设备列表：搜索、筛选、排序、分页、固定列
- 设备详情：基础信息、属性信息、状态信息、最近告警、最近操作
- 实时监控：趋势图、仪表盘、链路指标、历史曲线、Mock 自动刷新
- 告警中心：列表、详情、等级展示、状态流转
- 运维中心：分组统计、操作日志、批量启用/停用/删除/导出
